# VSG Internship Projects

During my internship at **VSG**, I developed three independent projects demonstrating different software architecture patterns and backend development practices using ASP.NET Core.

---

# Clean Code Web API

## Overview

A RESTful Web API developed following **Clean Code** principles, focusing on maintainability, readability, modularity, and scalability.

## Technologies

* C#
* ASP.NET Core Web API
* REST API
* AutoMapper
* FluentValidation
* HTML
* CSS
* JavaScript

## Highlights

* Clean and maintainable architecture
* Separation of concerns
* DTO mapping with AutoMapper
* Request validation with FluentValidation
* RESTful endpoints
* Modular service layer

---

# N-Tier Music Web API

## Overview

A music management application developed using **N-Tier Architecture**. The project separates the presentation, business, and data access layers while providing a modern web interface and RESTful backend services.

## Technologies

* C#
* ASP.NET Core Web API
* N-Tier Architecture
* REST API
* AutoMapper
* FluentValidation
* HTML
* CSS
* JavaScript

## Highlights

* Layered architecture
* Music management system
* Business and data layer separation
* DTO mapping with AutoMapper
* Input validation using FluentValidation
* RESTful API
* Responsive web interface
